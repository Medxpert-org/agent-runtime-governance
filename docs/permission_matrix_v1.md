# Permission Matrix v1（多智能体运行权限矩阵）

> 三级口径：🟢 可自治（全动作日志留痕 + 周期审计抽样）· 🟡 须运营者点头（审批闸 + 任务台账，无主不开单）· 🔴 无显式授权禁动（`code/redline_guard.py` 钩子自动拦，exit 2）。
> 升级链：执行席 E0 → 调度官 E1 → 治理中枢 E2 → 运营者 E3；升级必带 attempt log（试过什么 / 为何不行 / 诉求）。
> 版本：v1（2026-09-28）。

## 一、总表（域 × 三级）

| 域 / 动作 | 🟢 可自治 | 🟡 须运营者点头 | 🔴 禁动（钩子拦） |
|---|---|---|---|
| 文件 | 工作区内读写、整理、建稿、日志 | 移动/重命名工作区外文件；批量（>10）操作 | 删个人目录（用户桌面/下载/文档类）、系统目录、工作区整树、配置与凭据库目录；对根/家目录/通配符的递归删除 |
| 对外内容 | 草稿、内部研究、素材登记、排版 | 任何对外发送：公众号/社交渠道/邮件/网盘分享 | 以 MedXpert / SynomosAI 品牌发布未经权利门禁；外发件缺权属宣告块或缺名称状态标注；回头改动已发布内容 |
| 凭据 | 按精确键名读环境变量存在性；从本地凭据保险库取用 | 凭据轮换、新增站点登录登记 | 明文密钥进对话/命令/代码（ghp_/sk-/AKIA 等形态）；AI 持有或代注册用户凭据 |
| 代码 | 本地 git add/commit；分支操作；测试 | push 任何远端（先跑通道探针）；安装依赖 | force push、删库、删版本库目录、绕过发布闸 |
| 云部署 | 本地端口起服务、本地预览 | 联网部署/上线/绑定域名/连接外部服务 | pipe-to-shell 远程代码直接执行；未经点头的部署 |
| 财务 | 无 | 发票、订阅、充值、任何支付 | 一切自主支付 |
| 合规域 | 整理法规资料、翻译草稿、检索比对 | 监管提交结论、对外合规意见、客户交付件 | AI 签发临床/注册结论（技术能力 ≠ 执行授权，FDA-2026-N-7874 口径）；客户件出现个人姓名 |
| 成本 | 常规调用（单次、就低模型档） | 高耗操作（全量评测/长流水线/批量抓取）先报预估 | — |
| 实体注册 | — | — | 代注册实体/商标/域名/账号 |
| 共享看板 | 经带锁原子通道读写 | — | 绕锁直写共享看板 |

## 二、🔴 钩子覆盖清单（redline_guard.py v1）

| 编号 | 拦截模式 | 依据 |
|---|---|---|
| R1 | 毁灭性删除 × 危险目标（同一命令串内同时命中才拦） | 个人文件安全规则 |
| R1+ | 对根/家目录/通配符的裸递归删除 | 同上 |
| R2 | 明文密钥形态 / 硬编码密钥赋值（占位符豁免；匹配值不回显） | 密钥永不进对话铁律 |
| R3 | 磁盘格式化 / 注册表 HKLM 删除 / 卷影删除 / 磁盘分区 / 写盘清除类 | 系统破坏 |
| R4 | pipe-to-shell（下载器输出直接接 shell/脚本解释器） | 联网部署须运营者点头 |

## 三、已知边界（诚实声明）

1. 钩子只覆盖单平台四个工具入口（命令执行 / 文件写改），MCP 工具直调不在其内——靠连接器权限与派单模板约束。
2. 🟡 审批闸目前是制度闸（流程约束），不是代码闸。
3. 误拦/漏拦按「同类错误三击升级为硬门禁」规则修订正则。
